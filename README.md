## 忍了很久，最后还是打开了编辑器

作者做这个软件的出发点很简单：

**不想再被人从后面盯着屏幕看了。**

起初，作者以为只是偶尔路过，顺便瞟了一眼。

上班嘛，工位挨着工位，看见点什么也正常。作者没说什么，默默把窗口切了，接着干活。

后来发现，这个“偶尔”，出勤率比作者还稳定。

回消息，TA在看。  
查资料，TA在看。  
坐着看不清，TA还会站起来看。

**作者的工作有没有进展不好说，TA的观看进度倒是一直没落下。**

作者开始下意识地缩小窗口、切换页面，时不时回一下头。明明在用自己的电脑，愣是用出了一种偷偷摸摸的感觉。

有时候只是想回条私人消息，手已经放到键盘上了，还得先确认后面有没有观众。

说出来，怕场面尴尬。  
不说，自己一直膈应。

于是作者决定，先采取一点温和措施。

**买面镜子。**

往桌上一摆，既能看见后方，也算一个委婉的提醒：你看我屏幕，我看得见，差不多就行了。

作者觉得，话都说到这个份上了——虽然一句也没说——TA总该明白吧？

TA看见镜子了。

然后继续看屏幕。

哦？

**看习惯了是吧？**

作者终于发现，这面镜子最稳定的功能，是提醒自己：

TA又在看。

过一会儿再瞄一眼。

TA还在看。

钱花了，问题没解决，烦恼倒是从“感觉有人看”，升级成了“我看得清清楚楚”。

**别人照镜子整理仪容，作者照镜子积攒怒气。**

最不对劲的是，TA只需要看，作者却得负责整套配套服务：余光侦察、窗口切换、突然回头，顺便安慰自己“算了算了”。

凭什么？

我上个班，还得给自己的屏幕站岗？

忍了一次，又忍一次。终于有一天，作者看着镜子里的后方动静，想明白了：

**不能一直逆来顺受。**

**忍无可忍，那就重拳出击。**

于是，作者打开了编辑器。

就这样，**窥贼 Crazy** 诞生了。

它通过摄像头留意后方动静，尝试排除本人；检测到疑似围观时，按设置遮住需要保护的窗口，再把观察者的实时特写摆到屏幕上。

以前，TA看屏幕，作者不自在。

现在，TA看屏幕，屏幕里有TA。

**刚才不是看得挺投入吗？**

**看啊。今天你是主角。**

作者做这个工具，也没什么宏大的理想。

就是希望回消息的时候能好好回，查资料的时候能好好查，偶尔发个呆，也不用先从镜子里检查一下观众到齐没有。

有事直接问，想看先打个招呼。

**我负责上班。背后，交给窥贼。**

---

一个在 Windows 本机运行的屏幕哨兵：检测后方观察者、尝试排除本人，按需遮挡指定窗口，并用动态相框提醒围观者。

> v13.6 Beta · MIT 开源代码 · 本地运行。公开发行包不附带第三方人物 GIF，默认使用原创哨兵；可在设置中导入有权使用的本地素材。

## v13.6 的操作与流畅度改进

- 托盘、窗口和程序文件统一使用窥贼 Logo；不再显示蓝色系统信息图标。
- 深色控制台采用左侧后方画面、右侧本人录入 / 保护窗口 / 动画设置；小窗口下也保留主要操作入口。
- 持续取帧与人脸识别分开，只保留最新一帧。实时预览不再等识别完成；回敬和录像仍要求检测结果新鲜、身份核对通过。
- 点击“开始保护”自动打开相机、展开画面；首次使用进入本人录入指引，验证并保存后继续监测。启动时禁用重复开始，并提供取消入口。
- 用“收起画面 / 展开画面”替代显示复选框，只改变视频可见性；后台监测继续使用同一路相机。
- 修复 Windows 最大化窗口下预览不刷新的问题。刷新跟随相机新帧，识别暂未完成时也能继续播放画面。
- 相机断流时清除旧帧、提供重试入口；等待旧相机释放后再重开，已有遮挡继续保留。未设置遮挡窗口时明确显示“仅监测”。
- 多个检测框可拖动边缘和四角缩放、框内移动；点“新增框”或按住 Shift 拖动可在已有框内新增，支持撤销修改。
- 动态相框的人物区域扩大到两栏可用宽度的约 52%，主台词横跨底部大字显示；公开包仍使用原创哨兵。
- 启动、关闭和错误提示完整替换，按实际文字高度排列；录入指引修正深色对比度，失败后可以重试。
- 更新异常会暂停并提示，保留后续界面更新；已遮挡内容保持遮挡，等待用户主动恢复。

已通过 186 项程序测试（185 通过，1 项因公开源码不包含可选人物 GIF 而跳过）、独立 EXE 检查及不同窗口状态检查。在实际 Windows 最大化窗口下，用模拟视频验证了连续刷新、收起与展开、断流清除和重试流程；这些结果不能替代对具体摄像头驱动和工位环境的实测。

## v13 的检测与显示改进

- 完整画面检测加后方区域放大搜索，持续复查已找到的小脸，并合并重复脸框。
- 同一画面已认出本人时，明显分开的第二张脸也能作为额外入镜人物，不再必须靠清晰的大脸完成身份核对；本人不在画面或人物重叠时继续等待核对。
- 已核对的非本人允许至多 0.8 秒短暂模糊，出现身份冲突或交叉时重新确认。
- 遮罩已显示且位置、层级未变时不重复显示或定位；预览保留画布，只随新画面更新，减少覆盖其他窗口时的闪动。
- 人物特写若与受保护人脸重叠，显示“人物重叠，暂不显示特写”；动态角色可继续播放，该裁剪不会进入录像。

此前的指引与检测改进也保留：

- 高灵敏度检测到的脸会进入身份核对，避免被后续更高的隐藏门槛直接跳过。
- 身份待确认时可先遮挡内容；特写和录像继续要求确认非本人。
- 预览分别显示本人、非本人、待确认数量，并说明未触发原因。
- 圆环只随实际采集进度填充；新模板验证成功并保存后才替换旧模板。取消时保留原模板。
- 朝向筛选容忍短暂漏帧，明显转开时停止显示；它仍然不是精确眼动追踪。

## 使用体验

- 深色底色、低饱和绿、可见的键盘焦点与高 DPI 控件。
- “认识我”、相机预览与保护窗口直接放在主页；动作预览放在设置里。
- 支持多个检测区、多个保护区和应用窗口。窗口移动时，遮罩尝试跟随。
- 本人模板在 Windows 当前账户下加密保存；运行时不上传图像，不下载模型。
- 相机初始关闭。录像默认关闭，需要主动打开；只保存观察者原始特写，不录屏、不录声音。
- 动画素材在后台准备，按需缩放。没有可选人物素材时，使用代码绘制的原创几何哨兵。

## 运行

需要 Windows 10/11、64 位 Python 3.12、摄像头。依赖安装需要网络，程序正常运行使用仓库内的本地模型。

```powershell
git clone https://github.com/Jackied123456/Crazy---KuiZei.git
cd Crazy---KuiZei
py -3.12 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-small-mirror.txt
.\.venv\Scripts\python small_mirror.py
```

1. 点击“开始保护”，相机会自动打开并展开画面。首次使用会进入本人录入指引：确认画面里是你，跟着圆环转头，验证通过后点“保存并完成”，即可继续监测。也可单独从“认识我”一栏进入录入。
2. 点“设置检测区”调整后方范围。拖边缘或四角缩放、框内拖动可移动；点“新增框”或按住 Shift 拖动可新增多个框，完成后点“完成”。
3. 点“选择窗口”，选好需要遮挡的内容，再点“试遮挡”确认覆盖效果。未选择时仅监测，不代表内容已经遮挡。
4. 不想一直看视频时点“收起画面”，后台监测继续；“展开画面”恢复显示。“暂停保护”才会停止监测并关闭相机。动画预览与动作选择在“设置 → 动画与台词”中。

双击遮罩或按 `Ctrl+Alt+H` 恢复内容。窗口绑定只在当前会话有效，重启后需要重新选择。

## 限制

头部朝向加持续时间只是近似筛选，不能证明对方在阅读屏幕，也不能证明对方有恶意。摄像头角度、光线、遮挡和侧脸都会影响结果。

遮罩盖住同一块屏幕，也会遮住使用者看到的内容。它无法撤回已被看见的画面，不能代替物理防窥措施。全屏、高权限应用和不同显示缩放需要实测。

只有覆盖位置、可见性和窗口层级检查成功后，界面才报告“已遮挡”。出现观察者相框不等于内容已经保护。程序退出或崩溃后不保证遮罩继续存在。

这是 **Beta 测试版，当前仅供娱乐、未商业化**。这段说明不代替代码许可证或第三方素材授权。代码采用 MIT，允许商业使用；“未商业化”只说明本项目当前状态。

## 本地数据

默认目录为 `%LOCALAPPDATA%/Crazy/PublicBeta`。可以通过 `--data-dir` 指定独立目录。本源码仓库不包含已有模板、设置、录像或统计，不导入其他旧版应用的共享模板。

本人特征使用 Windows DPAPI 加密。录像是本地普通 AVI 文件，没有额外加密；当前 Windows 账户或有相应磁盘权限的程序可能读取它。见 [隐私说明](PRIVACY.md)。

Windows 发行程序为 `Crazy-v13.6-Beta.exe`。

本人模板是本机录入后才产生的独立文件，不在源码或发行包里；`models/` 的 YuNet / SFace 是所有用户共用的预训练模型，不是作者或其他使用者的人像资料。公开 GitHub 仓库会展示代码提交历史，但不会自动收集本机文件、摄像头画面或开发对话。

## 本地素材

Windows 程序支持 EXE 同目录的 `Crazy-local-media/`；其中 `programs.json` 必须与内置节目配置一致。附带目录不会进入公开包，已导入的本地素材优先。“删除导入素材”会停用附带目录，不删除目录原件；重新导入即可启用。

在“设置 → 动画与台词”选择“导入本地动图”，选择装有 GIF 的文件夹。可只准备部分动作；文件名与 slots 如下。

| 文件名 | 用途 |
| --- | --- |
| `patrol.gif` | 开场巡逻 |
| `close-warning.gif` | 近景提醒 |
| `ear-laugh.gif` | 大笑 |
| `arms-chin.gif` | 托腮观察 |
| `frown.gif` | 皱眉 |
| `salute-sleep.gif` | 敬礼收尾 |
| `megaphone.gif` | 广播提醒 |
| `black-straight.gif` | 单次回敬 |
| `tiny-heart.gif` | 友好收尾 |
| `tank-combo.gif` | 连招 |
| `red-barrage.gif` | 连续回敬 |
| `covered-giggle.gif` | 忍笑 |

单个 GIF 最多 20 MB、300 帧、200 万像素；整组最多 60 MB，并限制解码后的总帧像素。文件内容在后台检查，只导入已知文件名，用户提供的节目配置不会被导入。导入内容保存在独立本地数据目录，公开构建始终不携带这些文件。“删除导入素材”恢复本版本内置动画（公开版为原创哨兵），不删除本人模板、设置和录像。只导入你有权使用的内容。

## 常见问题

**运行时需要联网吗？** 安装 Python 依赖需要网络。模型随源码提供，应用的识别、遮挡和录像在本地进行；没有遥测或图像上传功能。

**下载后就会开摄像头、开始录像吗？** 不会。初始相机关闭，录像也默认关闭。开启录像后只保存观察者的原始特写，不录制桌面或声音。

**为什么本人也可能被框出来？** 请先完成“认识我”，并在实际工位光线下预览验证。本人排除与头部朝向筛选都可能误判，不能把提示当作窥屏行为的事实认定。

**为什么看不到人物动图？** 公开版默认显示原创哨兵。可在设置中导入有权使用的本地 GIF，具体文件名见上表。

**支持 macOS / Linux 吗？** 当前界面和保护窗口依赖 Windows 原生 API，尚未支持其他平台。

身份比对阈值参考 [OpenCV 的 SFace 示例](https://docs.opencv.org/4.12.0/d0/dd4/tutorial_dnn_face.html)，本人排除使用更严格的门槛。公开基准阈值不代表实际工位识别准确率。
